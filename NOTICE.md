# Provenance and redistribution

This repository contains an evaluation harness and a cleaned research notebook. It references and calls an external Stretch AI/DynaMem implementation, pretrained SigLIP and YOLOE models, and DynaBench data. It does **not** contain those third-party implementations, weights, or raw scene content.

The recorded diagnostic uses Stretch AI commit `6272b28e3ff7be482af3b427a4551d1772ebf7d7` and DynaBench revision `1d561e2de8718addf398e5e967f2c44dc015c366`. Please consult the original authors and each upstream project's terms before redistribution or derivative release.

The DynaBench public dataset page did not establish separate redistribution permission for its photos, frames, depth maps or derivative evidence images in the reviewed material, so these are intentionally excluded. This repository does **not** license the upstream data or weights. No additional license is asserted for this repository pending the owner's selection.

The experiment was developed with AI assistance. The accompanying result report is an analysis of a small diagnostic pilot rather than a claim of a published, novel or statistically established method.
